# 8-bit fighting game style bible

Use this for every GPT Image 2 asset so the game stays cohesive.

Visual identity:
- Original 8-bit arcade fighting game, inspired by the intensity of classic 3D martial arts games but with fully original characters and worlds.
- High-detail pixel art, readable silhouettes, dramatic martial arts poses, beautiful hand-placed pixel clusters, no smooth vector look.
- Rich color variety: deep navy shadows, teal highlights, warm gold lights, crimson accents, soft dusk sky gradients.
- Chunky 8-bit forms with 16-bit-level detail, crisp black or very dark outline, no blur, no anti-aliased painterly edges.
- Camera: side-view fighting game perspective, grounded floor line, characters seen full-body.

Sprite production rules:
- Generate on a flat chroma key background, preferably pure #00ff00, because GPT Image 2 currently does not support transparent backgrounds.
- Character should fit entirely in frame with no cropping.
- Keep the same costume, face shape, hair, palette, and proportions across animation frames.
- Avoid text, logos, watermarks, UI, motion blur, realistic photography, soft 3D rendering, and painterly brushwork.

Stage production rules:
- Side-view fighting arena background, horizontal composition.
- Floor must be clear and usable as a fighting plane.
- Include separate prompts for background, foreground floor, and optional animated detail layers.
